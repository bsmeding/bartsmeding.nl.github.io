# Large Home & Home Office Networking

Professionally managed networks for **large homes** and **home office** environments where **stability**, **speed**, and **reliability** are essential — multi-floor layouts, many devices, and serious remote work.

We deliver and operate complete **UniFi-based** network infrastructures with central monitoring, a secure VPN management layer, and automation. Not consumer Wi‑Fi kits — **standardised, reliable, enterprise-grade infrastructure** for residential use.

All management is **remote** (ticket/e-mail) via a secure management connection.

## Not included

This is a **managed network and smart home infrastructure service** — not consumer IT support. We deliver standardised, reliable, enterprise-grade infrastructure for residential and home office environments.

The following is explicitly **outside** the scope of these packages:

- Internet provider outages (ISP issues)
- End-user devices (laptops, phones, printers)
- Windows / macOS troubleshooting
- Unsupported routers or network equipment
- HACS / custom Home Assistant components
- Custom scripts or bespoke automation (available on project basis)
- Ad-hoc "computer help" tasks
