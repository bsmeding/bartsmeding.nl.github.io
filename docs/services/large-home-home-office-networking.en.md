# Large Home & Home Office Networking

Professionally managed networks for **large homes**, **business-grade home environments**, and **hybrid home/office networks** — where stability, speed, and reliability matter. Think multi-floor layouts, many connected devices, remote work, and business use from home.

We deliver and operate **UniFi-based** infrastructures with central monitoring, a secure management VPN, and lifecycle automation. This is not consumer mesh Wi‑Fi: it is **standardised, enterprise-style infrastructure** for demanding homes and home offices.

We **prefer UniFi**; enterprise brands (Arista, Juniper, Cisco, …) are available **by agreement**. Heavy **automation** keeps managed costs down — that is not possible with standard consumer home networking gear. Hardware supply is optional; see the [Services overview](index.md) for platform, enterprise, and hardware options.

All ongoing management is **remote** (ticket/e-mail) via a secure management connection.

## Not included

This is a **managed network and smart home infrastructure service** — not consumer IT support.

The following is explicitly **outside** the scope of these packages:

- Internet provider outages (ISP issues)
- End-user devices (laptops, phones, printers)
- Windows / macOS troubleshooting
- Consumer mesh, ISP routers, and unsupported network gear (enterprise brands by agreement — see [Services overview](index.md))
- HACS / custom Home Assistant components
- Custom scripts or bespoke automation (available on project basis)
- Ad-hoc "computer help" tasks
