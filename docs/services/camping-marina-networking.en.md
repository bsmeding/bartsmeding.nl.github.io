# Camping & Marina Networking

Managed network solutions for **campings**, **marinas**, and **hospitality** locations where reliable WiFi, guest access, and infrastructure continuity are essential.

We design and operate scalable **UniFi networks** for outdoor environments, recreation areas, and waterfront infrastructure — including **guest networks**, **camera networks**, and segmentation of critical systems.

All solutions are **remotely managed** via central monitoring and secure VPN management. Not consumer WiFi — standardised, enterprise-grade outdoor network infrastructure built for reliability across a full season.

## Not included

This is a **managed network infrastructure service** — not consumer IT support. We deliver standardised, enterprise-grade outdoor networks for hospitality environments.

The following is explicitly **outside** the scope of these packages:

- Internet provider outages (ISP issues)
- Guest end-user devices (laptops, phones, tablets)
- Windows / macOS troubleshooting
- Unsupported equipment brought by guests or tenants
- Ad-hoc "computer help" tasks
